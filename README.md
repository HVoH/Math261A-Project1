Project 1:
Is Average Adjusted Gross Income per Tax Return Associated with the Percentage of EV Registration Across California ZIP codes in 2023?

Author:             HIEN VO  

Submission Date:    Sep 25, 2026

Project Description:   
This project uses linear regression to investigate whether EV regristration is associated with average AGI. 
Using 2023 income data and individual EV registration data aggregated by ZIP code, the analysis examines whether the areas with higher average AGI tend to have a higher percentage of EV regristrations.


Project structure:  
    - `P1.qmd` : R code and written analysis for the project
    
    - `P1.pdf' : The PDF file that generated from `P1.qmd`
    
    - `DataP1/` : Folder containing the raw data sets and the data dictionaries
        `vehicle-fuel-type-count-by-zip-code-2023.csv`: Vehicle registration data by Zip code.
        `2024_personal_income_tax_statistics_by_zip_code.csv`: Personal income tax data by Zip code.
        `personal_income_tax_statistics_by_zip_code_data_dictionary.pdf`
        `Vehicle Fuel data-dictionary.pdf'
        
    - `README.md`: Project information  
    
 
Data Sources:  

The two data sets are obtained from the California Open Data sources.  
The data set "Personal income tax data by Zip code"  is published by California Franchise Tax Board.   
https://data.ca.gov/dataset/personal-income-tax-statistics-by-zip-code  

The data set "Vehicle registration data by Zip code" is provided by DMV Information Policy and Liaison Branch.  
https://data.ca.gov/dataset/vehicle-fuel-type-count-by-zip-code
